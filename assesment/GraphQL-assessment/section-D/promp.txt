# Professional Development Prompt — React + Apollo Client Food Category Filter App

You are an expert React.js frontend developer. Build a complete, clean, professional-level food browsing/filter application using **React + Vite + Apollo Client + GraphQL**.

## 1. Technology Requirements

Use exactly:

* React.js
* Vite
* JavaScript (NOT TypeScript)
* Apollo Client
* GraphQL
* CSS
* React Hooks

Install only these packages:

```bash
npm install @apollo/client graphql
```

Do NOT add unnecessary libraries such as Axios, Redux, React Query, Tailwind, Bootstrap, Material UI, or any backend/server package.

The application must work entirely from the React frontend.

---

## 2. Important Apollo Client Version Requirement

Assume the project uses the **latest Apollo Client version**.

Be careful with Apollo Client import paths because Apollo Client v4 may not export React hooks/components from the same path as older versions.

Use the correct imports for the installed Apollo Client version.

For Apollo Client v4, React-specific APIs should be imported from the appropriate React entry point, for example:

```js
import { ApolloProvider, useQuery } from "@apollo/client/react";
```

Do NOT blindly use:

```js
import { ApolloProvider } from "@apollo/client";
import { useQuery } from "@apollo/client";
```

if those imports are incompatible with the installed version.

The Apollo Client must be configured correctly with:

* ApolloClient
* HttpLink
* InMemoryCache
* ApolloProvider

Do NOT create an Apollo Client without a valid `link`.

# 3. Application Requirement

Create a page for a food browsing application.

The page should contain:

1. A professional page heading.
2. Food category filter chips below the heading.
3. Food items displayed below the filter chips.
4. Clicking a category chip should immediately filter the food items.
5. The selected chip must have a clearly different visual style.
6. A loading spinner must be displayed while the GraphQL category request is loading.
7. A readable error message must be displayed if the GraphQL request fails.

# 4. GraphQL Requirement

Use Apollo Client's `useQuery` hook to fetch food categories from a GraphQL API.

Create a GraphQL query similar to:

```graphql
query GetCategories {
  categories {
    id
    name
  }
}
```

However, **do not assume that this exact query works with an arbitrary API**.

Before writing the final code:

* Make sure the selected GraphQL API actually supports categories.
* Make sure the query matches the API's real schema.
* Make sure the returned field names match the query.
* Do not invent GraphQL fields.
* Do not use a REST API as a replacement.
* Do not create a backend server.
* Do not use MockedProvider.

If a public GraphQL API does not provide a suitable food-category schema, clearly state that and use a GraphQL API that actually supports the required category query.

The final application must use Apollo Client's `useQuery`.

# 7. Category State

Use React's `useState` to track the currently selected category.

Example:

```js
const [selectedCategory, setSelectedCategory] = useState("All");
```

The initial state should display all food items.

When the user clicks a category chip:

```text
User clicks category
        ↓
setSelectedCategory(category)
        ↓
React re-renders
        ↓
Food items are filtered
        ↓
Only matching items are displayed
```

Do NOT reload the page.

Do NOT make another API request when clicking a category.

The filtering must happen locally using the hardcoded food-item array.

# 9. Filtering Logic

Filter the hardcoded food array based on `selectedCategory`.

The logic must behave like this:

```text
Selected category = "All"
        ↓
Show every food item

Selected category = "Pizza"
        ↓
Show only foodItems where category === "Pizza"

Selected category = "Burger"
        ↓
Show only foodItems where category === "Burger"
```

Use JavaScript's `filter()` method.

Do not mutate the original food array.

Do not store the filtered array unnecessarily in state.

Prefer deriving the filtered list from:

```js
selectedCategory
```

and:

```js
foodItems
```

# 12. Loading State

While the GraphQL query is loading, do NOT immediately render the category chips.

Instead display a professional loading spinner.

Example:

```text
Food Menu

        ⟳
   Loading categories...
```

The component should use:

```js
const { loading, error, data } = useQuery(GET_CATEGORIES);
```

Then handle:

```js
if (loading) {
  return <LoadingSpinner />;
}
```

The loading state must be visible while the request is pending.

Create a reusable `LoadingSpinner` component.

Do not use an external spinner library.

Use CSS for the spinner.
